# Word by Word

Інтерактивний рідер для вивчення англійської через читання — з перекладом українською.

Ця збірка містить повітряний дизайн: єдиний світлий фон секцій, виразну типографіку, тонкі роздільні лінії та два рівноправні акценти — синій #3B6FD2 і світлий кораловий #C77D8D. Іконки 24 історій розподілені порівну між ними, а основні кнопки мають контур замість заливки.

## Можливості

- 24 оригінальні історії рівнів A1–B2 із кількома абзацами в кожній;
- переклад кожного слова та заголовків за кліком;
- плавна блакитна підсвітка при наведенні та коралове виділення обраного слова;
- єдина світла тема з м’якими кольоровими акцентами;
- подвійний клік і клік на порожньому місці закривають картку перекладу;
- картка перекладу з’являється поряд з обраним словом;
- загальний словник із 1176 слів, переглядом за першою літерою і пошуком за словом або перекладом;
- переклад у словнику показується одразу, а наведення м’яко підсвічує слово;
- список слів продовжується автоматично під час прокрутки;
- кнопка «Спробувати рідер» відкриває розділ читання;
- хедер закріплюється при прокрутці та зменшується, а переходи до секцій враховують його висоту;
- завантаження TXT, MD і FB2 для читання; EPUB позначається на обробку.

## Запуск

Потрібен Node.js 22 або новіший.

```bash
npm install
npm run dev
```

Для перевірки збірки:

```bash
npm run build
```

Для частих і неоднозначних слів використовується вбудований словник. Решта перекладів спершу запитуються через DeepL, а MyMemory використовується як резервний варіант.
